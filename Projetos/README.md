## 🚀 Projetos
A consolidação do conhecimento. Aplicação prática dos conceitos através do ciclo de vida completo do desenvolvimento de software.

### 📌 Conteúdo Programático Geral
* Metodologias de gerenciamento (Ágil vs. Cascata).
* Planejamento de sprint e estimativa de esforço.
* CI/CD (Integração e Entrega Contínua).
* Versionamento de código e fluxo de trabalho em equipe.

### 🌀 Fluxo de Trabalho com Git (GitFlow)
```text
[Main] -----------> (Versão em Produção)
  ^
[Develop] --------> (Ambiente de Homologação/Testes)
  ^
[Feature/Nova] ---> (Desenvolvimento da funcionalidade)
```

### 📋 Artefatos de Entrega
* **Código Fonte:** Repositório organizado e documentado.
* **Histórias de Usuário:** Escopo focado no valor para o cliente final.
* **Pipeline de Build:** Automatização que garante que o projeto compila e passa nos testes a cada alteração.
