# 🏫 Repositório de Aulas - Tecnologia da Informação (2º Termo)

Este repositório reúne os conteúdos, materiais de apoio, exercícios e projetos desenvolvidos durante o **2º Termo** do curso de Tecnologia da Informação. As disciplinas aprofundam os conhecimentos adquiridos no primeiro semestre, com foco no desenvolvimento de aplicações web, modelagem de bancos de dados e execução de projetos de software.

---

## ⚙️ 1. Back-end

Introdução ao desenvolvimento do lado do servidor, abordando a construção de APIs, integração com bancos de dados e organização de aplicações utilizando boas práticas de programação.

- **Fundamentos do Backend:** Arquitetura cliente-servidor e funcionamento do protocolo HTTP.
- **Desenvolvimento de APIs:** Criação de endpoints seguindo o padrão REST.
- **Frameworks e Ferramentas:** Estruturação de aplicações utilizando frameworks modernos.
- **Persistência de Dados:** Integração entre aplicações e bancos de dados relacionais.
- **Autenticação e Segurança:** Conceitos de autenticação, autorização e proteção de informações.
- **Boas Práticas:** Modularização, tratamento de erros, validação de dados e versionamento com Git.

---

## 🌐 2. LIMA – Linguagem de Marcação

Estudo das tecnologias fundamentais para o desenvolvimento de interfaces web, explorando a construção de páginas modernas, responsivas e interativas.

- **HTML5:** Estruturação semântica de documentos e formulários.
- **CSS3:** Estilização, Flexbox, Grid Layout e responsividade.
- **JavaScript:** Manipulação do DOM, eventos, funções e interação com o usuário.
- **Design Responsivo:** Desenvolvimento de interfaces adaptáveis para diferentes dispositivos.
- **Boas Práticas:** Organização do código, acessibilidade e padronização de projetos front-end.

---

## 🗄️ 3. Banco de Dados

Disciplina voltada à modelagem, implementação e manipulação de bancos de dados relacionais, utilizando SQL para armazenamento e recuperação de informações.

- **Modelagem de Dados:** Diagramas Entidade-Relacionamento (DER) e Modelo Relacional.
- **Normalização:** Aplicação das formas normais para reduzir redundâncias.
- **SQL (DDL):** Criação e alteração de bancos de dados, tabelas e restrições.
- **SQL (DML):** Inserção, atualização e remoção de registros.
- **SQL (DQL):** Consultas utilizando filtros, ordenação, agrupamentos e funções.
- **Relacionamentos:** Chaves primárias, estrangeiras, integridade referencial e cardinalidade.
- **Consultas Avançadas:** JOIN, subconsultas, funções de agregação e views.

---

## 📚 4. Projetos

Disciplina voltada à aplicação integrada dos conhecimentos adquiridos, promovendo o desenvolvimento de soluções reais utilizando metodologias de planejamento, organização e trabalho em equipe.

- **Levantamento e Planejamento:** Definição de escopo, cronograma, requisitos e entregáveis.
- **Gestão de Equipes:** Organização de tarefas, colaboração e acompanhamento das atividades.
- **Desenvolvimento Integrado:** Aplicação dos conhecimentos das demais disciplinas na construção de um projeto completo.
- **Documentação Técnica:** Produção de relatórios, documentação do sistema e apresentação dos resultados.

---

## 🎯 Objetivo do 2º Termo

Consolidar os conhecimentos de desenvolvimento de software por meio da criação de aplicações completas, integrando interfaces web, lógica de negócio, bancos de dados e metodologias de gerenciamento de projetos, preparando o estudante para desafios mais avançados no desenvolvimento de sistemas.
