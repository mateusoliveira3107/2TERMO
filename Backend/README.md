## ⚙️ Backend
O motor do sistema. Responsável pelas regras de negócio, segurança, processamento de dados e integração com o banco de dados.

### 📌 Conteúdo Programático Geral
* Arquitetura de software no servidor.
* Criação e consumo de APIs.
* Autenticação, autorização e segurança de dados.
* Otimização de performance e processamento assíncrono.

### 🔌 APIs: REST vs. GraphQL
* **REST (Representational State Transfer):** Baseado em métodos HTTP puros (`GET`, `POST`, `PUT`, `DELETE`). Utiliza endpoints fixos para cada recurso.
* **GraphQL:** Linguagem de consulta onde o cliente pede exatamente os dados que precisa. Evita o tráfego de dados desnecessários (*overfetching*).

### 🛠️ Tecnologias e Ecossistema
* **Linguagens Populares:** Node.js (JavaScript/TypeScript), Python, Java, C#, Go.
* **Comunicação:** JSON, XML e protocolos como WebSockets para tempo real.
