## 2. 📝 LIMA – Linguagem de Marcação
Estruturação e semântica de dados e documentos. Foco na organização hierárquica das informações para interpretação de sistemas e navegadores.

### 📌 Conteúdo Programático Geral
* Conceitos de tags, elementos e atributos.
* Semântica e acessibilidade na web.
* Formatos de intercâmbio de dados estruturados.

### 📊 Comparativo de Formatos Comuns

| Formato | Características Principais | Cenário de Uso Ideal |
| :--- | :--- | :--- |
| **HTML** | Base da web. Utiliza tags hierárquicas estruturadas. | Construção de páginas e interfaces web. |
| **XML** | Armazena dados de forma legível por humanos e máquinas. | Notas fiscais eletrônicas (NF-e) e sistemas legados. |
| **Markdown** | Sintaxe leve de texto puro para formatação rápida. | Documentação técnica, wikis e arquivos `README.md`. |
