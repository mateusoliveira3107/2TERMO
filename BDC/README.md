## 3. 🗄️ Banco de Dados
O coração do armazenamento. Onde a informação é modelada, guardada de forma segura e recuperada de maneira eficiente.

### 📌 Conteúdo Programático Geral
* Modelagem de dados (Conceitual, Lógico e Físico).
* Linguagem de consulta e manipulação de dados.
* Integridade, transações e propriedades ACID.

### 🔄 Relacional (SQL) vs. Não Relacional (NoSQL)
* **SQL (Relacional):** Dados estruturados em tabelas com linhas e colunas rígidas. Perfeito para sistemas com regras financeiras ou complexas relações.
  * *Exemplos:* PostgreSQL, MySQL, SQL Server.
* **NoSQL (Não Relacional):** Alta flexibilidade. Armazena dados em documentos, grafos, chaves-valor ou colunas. Ideal para grandes volumes e rápida escala.
  * *Exemplos:* MongoDB (Documentos), Redis (Chave-Valor).

### 📐 Conceitos Críticos
* **Chave Primária (PK):** Identificador único de um registro.
* **Chave Estrangeira (FK):** O elo que cria o relacionamento entre tabelas diferentes.
